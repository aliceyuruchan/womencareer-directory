# Tally 中文表单文案：申请入驻 Women Career Resources

表单链接： https://tally.so/r/dWokyz

## 表单标题

推荐资源给 Women Career Resources

## 表单说明

推荐一个可信的女性职业发展资源。我们会根据相关性、可信度、实用性和维护状态进行人工审核，审核通过后收录到目录中。

## 题目

1. 资源名称
- 类型：短文本
- 必填：是

2. 官方网站链接
- 类型：URL
- 必填：是
- 占位提示：例如 https://example.com

3. 一句话介绍
- 类型：长文本
- 必填：是
- 占位提示：请简要说明这个资源提供什么内容，以及适合谁使用。

4. 资源分类
- 类型：单选
- 必填：是
- 选项：
```text
社群
学习
书籍
奖学金
奖助项目
导师制
会议 / 活动
工具
播客
通讯
研究报告
开源资源
其他
```

5. 主要面向人群
- 类型：长文本
- 必填：是
- 占位提示：例如在校生、早期职业人士、转型者、女性科技从业者、创业者、设计师、工程师等。

6. 服务地区
- 类型：单选
- 必填：是
- 选项：
```text
全球
中国
亚洲
欧洲
北美
其他
```

7. 资源语言
- 类型：多选
- 必填：是
- 选项：
```text
中文
英文
多语言
其他
```

8. 费用
- 类型：单选
- 必填：是
- 选项：
```text
免费
付费
部分免费
不确定
```

9. 这个资源目前是否仍在活跃维护？
- 类型：单选
- 必填：是
- 选项：
```text
是
否
不确定
```

10. 为什么推荐收录这个资源？
- 类型：长文本
- 必填：是
- 占位提示：请说明它为什么可信、实用，或为什么适合女性职业发展相关用户。

11. 你与这个资源的关系
- 类型：单选
- 必填：是
- 选项：
```text
创始人或团队成员
社群成员
用户或参与者
合作方
独立推荐者
其他
```

12. 你的姓名
- 类型：短文本
- 必填：否

13. 联系邮箱
- 类型：邮箱
- 必填：是
- 占位提示：如需补充信息，我们可能会通过邮箱联系你。

14. 其他补充信息
- 类型：长文本
- 必填：否
- 占位提示：可以补充 Logo 链接、社交媒体链接、申请截止时间、参与资格或其他审核信息。

## 提交成功提示

感谢你的推荐。我们会人工审核提交内容，并将符合标准的资源收录到 Women Career Resources 目录中。
