# Tally Form Draft: Submit a Resource

Use this form to collect resource submissions for Women Career Resources.

## Tally AI Prompt

Copy this prompt into Tally AI to generate the form:

```text
Create a clean, professional English application form titled "Submit a Resource to Women Career Resources".

The form is for people who want to recommend or submit a trusted resource for a curated women career development directory. Keep the tone concise, trustworthy, and international. Avoid marketing language.

Intro description:
"Recommend a trusted resource for women’s career development. We review submissions for relevance, credibility, and usefulness before adding them to the directory."

Fields:

1. Resource name
Type: Short answer
Required: Yes

2. Official website URL
Type: URL
Required: Yes

3. One-sentence description
Type: Long answer
Required: Yes
Helper text: "Briefly explain what the resource offers and who it helps."

4. Resource category
Type: Multiple choice
Required: Yes
Options:
Community
Learning
Book
Scholarship
Fellowship
Mentorship
Conference
Tool
Podcast
Newsletter
Research
Open Source
Other

5. Primary audience
Type: Long answer
Required: Yes
Helper text: "Who is this resource designed for? For example: students, early-career professionals, women in tech, career changers, founders, designers, engineers, etc."

6. Region served
Type: Multiple choice
Required: Yes
Options:
Global
China
Asia
Europe
North America
Other

7. Resource language
Type: Checkboxes
Required: Yes
Options:
English
Chinese
Multiple languages
Other

8. Cost
Type: Multiple choice
Required: Yes
Options:
Free
Paid
Mixed
Not sure

9. Is this resource currently active?
Type: Multiple choice
Required: Yes
Options:
Yes
No
Not sure

10. Why should this resource be included?
Type: Long answer
Required: Yes
Helper text: "Tell us why this resource is credible, useful, or relevant for women’s career development."

11. Your relationship to this resource
Type: Multiple choice
Required: Yes
Options:
Founder or team member
Community member
User or participant
Partner
Recommending as an independent user
Other

12. Your name
Type: Short answer
Required: No

13. Contact email
Type: Email
Required: Yes
Helper text: "We may contact you if we need clarification."

14. Additional notes
Type: Long answer
Required: No
Helper text: "Optional: share a logo URL, social link, application deadline, eligibility details, or anything else we should know."

Closing message:
"Thank you for your submission. We review resources manually and will add selected submissions to the directory if they meet our criteria."
```
